# JSONWisdom Control Center

## Purpose

This repository is the observation and coordination layer for Jay Wisdom's GitHub work.

Jay Wisdom is the authority. Automation may inspect, organize, summarize, and propose. It may not silently archive, delete, merge, publish, spend, sign, or declare any repository canonical.

## Current phase

**Phase 0 — Observe before reorganizing**

No existing repository is modified by this control-center branch.

## Repository classifications

- `UNKNOWN`
- `ACTIVE_CANDIDATE`
- `LEGACY_CANDIDATE`
- `EVIDENCE_CANDIDATE`
- `DUPLICATE_CANDIDATE`
- `PRIVATE_REVIEW_REQUIRED`

A classification is a review label, not a final judgment.

## First mission

1. Inventory repositories controlled by `jsonwisdom`.
2. Detect likely project families and duplicates.
3. Identify on-chain, provenance, evidence, agent, and ReceiptOS-related repositories.
4. Record unresolved questions in `ASK_JAY.md`.
5. Make no destructive changes.
