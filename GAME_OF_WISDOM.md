# Jay’s Game of Wisdom 🎮⚙️🧌

Jay’s Game of Wisdom is a lifetime knowledge RPG built across GitHub repos, public proof, learning quests, family memory, receipts, badges, and mints.

It is not fantasy pretending to be truth.
It is a playable learning world where every achievement can point back to evidence.

## Core Rule
No receipt, no badge.
No badge, no mint.
No fake green.

## Goblins
Goblins are failure modes made playable.

- Fake Green Goblin — claims success without evidence
- Broken Link Goblin — points to missing repo/file/tx
- Clown Authority Goblin — pretends narrative equals proof
- Drift Goblin — changes meaning between versions
- Mint Goblin — wants trophy before receipt
- Privacy Goblin — tries to expose family/private data
- Branch Goblin — confuses default branch, PR, and live state
- Dependency Goblin — breaks repo build chain
- Memory Goblin — loses project continuity
- Gate Goblin — skips required verification step
- Publisher Drift Goblin — unpublished local edits exist before public mutation
- Zora Gate Goblin — mint portal exists but mint eligibility is not proven
- Canon Bundle Goblin — zipped canon exists locally but must be unpacked and verified before public claim
- Civic Leaf Goblin — civic files exist locally but need receipt chain before badge or mint
- Agent Goblin — assistant or agent code exists but must not claim authority

Defeating a goblin requires a receipt, not an opinion.

## Mint Rule
A mint is the trophy, not the proof.

Mint eligibility requires:
- Quest completed
- Receipt exists
- Badge awarded
- Public memory is safe
- Mint gate approved

## Cloud Shell Arena Rule
No local surface becomes public canon until repo, branch, commit, and receipt are verified.

## Guiding Idea
