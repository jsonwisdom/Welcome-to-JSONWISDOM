📐 The museum mathematics

Sine controls vertical movement; cosine controls horizontal movement. Both convert an angle into coordinates around Julie.

x = centerX + radius × Math.cos(angle)
y = centerY + radius × Math.sin(angle)

Your museum renderer also uses Math.sin to generate color intensities; this interactive orbit is a teaching adaptation, not a claim that museum code uses this layout.
